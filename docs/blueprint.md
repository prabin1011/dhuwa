# **App Name**: The Easy Way Out

## Core Features:

- AI Carr Chatbot: AI Chatbot: Simulate a direct, psychological conversation based on Allen Carr's principles. This tool analyzes user inputs and mirrors back their thoughts, providing counter-arguments to nicotine addiction.
- Progress Tracking: Progress Tracker: Visualize the user's journey with clear metrics on cigarettes avoided, money saved, and health improvements over time.
- Daily Tasks: Daily Missions: Provide users with targeted micro-tasks (insights from Allen Carr's easy way book) designed to engage with them every day and push toward quitting smoking.
- Inspirational Content: Inspirational Content Feed: A personalized feed delivering daily motivational quotes, success stories, and Allen Carr excerpts to reinforce the mindset shift.
- Urge Journal: Urge Journal: Allow users to log and analyze their smoking urges. Note when, where, why, and at what time the user feel urged. Users can track it so the tool can generate insight on it.

## Style Guidelines:

- Primary color: Gentle teal (#74D1BC) to promote calmness, healing and recovery.
- Background color: Light warm grey (#EDEDED) to keep UI elements visible and avoid distracting the user. 
- Accent color: Muted coral (#E07A5F) for important prompts or calls to action; it must be used sparingly to nudge gently, not shout.
- Body text font: 'PT Sans', sans-serif for readability. Headline font: 'Belleza', sans-serif, for a warm human-centered feeling. 
- Note: currently only Google Fonts are supported.
- Clean, minimalist icons that visually represent progress, health, and well-being. They will contribute to sense of achievement without feeling cluttered.
- Smooth transitions and subtle animations that give positive reinforcement.
